## The Aim
We have to develop brand new, highly easy to use for school students, and a selft contained simulator software to simulate circuits using Arduino Uno, Arduino Nano, ESP32, ESP8266, Raspberry Pi Pico W.
## How should it work?
The students will build the circuits in this software and import their relevant programs from the relevant software like Arduino IDE, Thonny, etc. and then simulate the circuit in this software.
## How should it look like?
We have to develop it just like the UI of modern Arduino and other simulators available on the net.
