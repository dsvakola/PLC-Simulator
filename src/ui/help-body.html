PLC Simulator User Guide

PLC Simulator lets you learn how a programmable logic controller (PLC) works. You write a program, put the simulated CPU into RUN, and watch what it does with its inputs and outputs. Everything works offline, on your own computer.

What a PLC does

A PLC is a small industrial computer that controls machines. It works in a never-ending loop called the scan cycle:

  1. It reads all its inputs (push buttons, switches, sensors): I1 to I8.
  2. It works out the program, block by block.
  3. It writes the results to its outputs (lamps, contactors, motors): Q1 to Q4.

Then it starts again. A full cycle takes a few milliseconds, so the machine seems to react at once.

The window

  • Program tab: draw your program as a function block diagram (FBD). Drag blocks from the left and join their pins.
  • Control Panel tab: the academy's PLC training panel, with the field devices you add and the wires you draw.

Drawing the program

  • Drag blocks from the left onto the drawing area.
  • To join two blocks, press on a pin, drag to a pin of the other block and let go. A straight line follows the mouse; the pin it will join shows a green dot (a red dot if it cannot take the wire). The wire then finds its own way at right angles. If you let go elsewhere, no wire is made.
  • Click a wire to select it: red squares mark its corners and blue dots its pieces. Drag a piece (or the wire itself) or a corner to change the path. Double-click a red square or blue dot to let the path be drawn automatically again. When you move a block alone, its wires find their way again.
  • An output block Q also has an output pin: wire it back into the program to make a latch, for example Q1 = (I1 OR Q1) AND NOT I2.
  • A free input of an AND or NAND counts as 1, a free input of an OR, NOR or XOR counts as 0. The small grey 1 or 0 beside the pin shows it.
  • Ctrl+A selects every block; draw a frame on an empty spot to select the blocks inside it; Shift+click adds a block. Drag one selected block to move them all. Selected blocks show red corners.
  • Ctrl+X, Ctrl+C and Ctrl+V cut, copy and paste blocks (with the wires between them). A pasted output gets a free Q number.
  • Right-click a block, a wire or an empty spot for a menu of what can be done there. This works on the Control Panel too.
  • Double-click an input I1 to I4 for its simulation mode: Switch (the default), Momentary push button (make), Momentary push button (break) or Frequency. It is the same setting as the switch on the Control Panel.
  • Every dialog window can be moved by its title, so you can see the diagram behind it. While a dialog is open, the program cannot be closed.
  • The middle mouse button moves the view, in the Program tab and on the Control Panel. On the Control Panel you can also drag an empty spot.

Testing the program in the Program tab

While the simulation runs, every connection shows its signal, as in the usual PLC software: red for 1, blue for 0, pin stubs included, and a block whose output is 1 gets a red frame. A strip under the diagram shows each input and output the program uses:

  • An input in Switch mode is a small slide switch: click it to switch it on or off. A push button works while you hold the mouse button down. A frequency input switches by itself. I5 to I8 are set by the devices wired on the Control Panel.
  • Each output is a lamp that lights when it is on.
  • On the right: run, pause (time stands still) and stop, the time of the simulated clock, and the clock button.
  • Esc stops the simulation.

Tools > Simulated clock sets the date and time the weekly and yearly timers see: the PC's clock or a date and time you choose. It can run at real time, a minute every second, or an hour every second, so timers can be tested without waiting.

The Control Panel

The panel is wired inside, like the real one. You cannot see or change that wiring:

  • The four lamps Q1 to Q4 light when those outputs are on.
  • The four switches I1 to I4 feed those inputs. Double-click a switch to make it NO or NC, and momentary (a push button) or maintained (stays where you put it).
  • The Q connector has three terminals for each output: + (24 V while the output is on), − (0 V) and earth. Join a load between + and −, and join the earth terminal of a motor to earth.
  • The I connector has three terminals for each of I5 to I8: + (+24 V), − (0 V) and S (the signal to the PLC). A switch or 2-wire sensor goes from + to S. A 3-wire sensor: brown to +, blue to −, black to S.
  • Only I7 and I8 read analog signals (0 to 10 V). In the program they are AI1 (I7) and AI2 (I8), counting 0 to 1000 for 0 to 10 V. A PT100 sensor is read through a temperature module inside the panel: white wire to S, both red wires to −. Its value is the temperature in tenths of a degree (25.0 °C reads 250).

Drag devices from the right onto the board or onto the bench below it. Drag from one terminal to another to draw a wire. Drag the middle of a wire to bend it at any angle; hold Shift for a 90° bend. Double-click a bend to remove it, drag a wire end to move it to another terminal, and right-click a wire to change its colour, make it straight or curvy, or delete it. New wires are straight; Tools > Options can make them curvy.

At 100% zoom the board fills the width of the window. Ctrl + mouse wheel zooms in and out, keeping the top-left corner in place.

Check wiring finds short circuits, wires to nowhere and duplicate wires, and gently warns about a motor that is not earthed.

Simulate

Press Simulate on the toolbar (or F3) to put the PLC into RUN. The program then runs scan by scan in real time, with real timers, and follows exactly the wires you drew:

  • Click the switches and push buttons. A momentary one works while you hold the mouse button; a maintained one changes over with each click.
  • Click a sensor to put a target in front of it, and again to take it away.
  • Click a potentiometer or PT100 for its slider.
  • Lamps light, motors turn (backwards if wired the wrong way round), buzzers and hooters sound.
  • A short circuit switches the 24 V supply off, like a real fuse. Stop, correct the wiring and run again.

Press Stop (or F3 again) to go back to STOP. Nothing can be changed while the simulation runs.

The SCADA Screen

The SCADA Screen tab is an operator screen, like the touch panel of a real machine. Drag items from the right onto the screen and double-click each one to link it to a point of the PLC:

  • Push button and Switch: work on I1 to I4 (the board switches) or on a marker M. A marker that is not written by the program keeps what the screen writes, so the program can use it as an input.
  • Slider: sets an analog marker AM.
  • Lamp, Motor, Valve, Conveyor: show an on/off point (I, Q or M).
  • Number display, Bar graph, Tank: show an analog point (AI1, AI2 or AM). "Show the value times" scales it, for example 0.01 shows AI1 in volts and 0.1 shows a PT100 in °C.
  • Text: a title or a note.

Check screen finds items that are not linked, or linked to a point they cannot use. Press F3 to run the screen with the program. File > Examples > SCADA screens has ready examples.

SCADA screen on another PC

Another PC on the same network can show the SCADA screen and use its buttons, switches and sliders, in its web browser, with nothing to install:

  1. On this PC: Simulation > Allow SCADA connection from another PC. A box shows an address such as http://192.168.1.20:8090 and a 4-digit code. If Windows asks, allow PLC Simulator on private networks.
  2. On the other PC: open that address in the web browser and type the code.
  3. Press F3 on this PC. The other PC shows the screen live.

Switch it off again in the same menu. Only PCs that know the code can connect, and nothing is sent to the internet.

Examples

Every instruction in the list on the left has a ready example with its wiring on the Control Panel: File > Examples, or right-click an instruction and choose Open the example. Each example opens as a new project; press F3 to try it.

Projects and files

A project is saved as one .vsaplc file. When you save over an older file, the previous version is kept beside it as .vsaplc.bak, so you can always go back one step. Double-click a project file in Windows to open it in PLC Simulator.
